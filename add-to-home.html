ホーム画面に追加する

アプリのように、一度の操作で開けるようになります。追加は無料で、インストールも必要ありません。

iPhone・iPad

Safari で開いてください。Chrome など他のブラウザでは追加できません。

  1. Safari で washokuzai-calendar.com を開く
  2. 画面下の 共有（四角から矢印が出ているマーク）を押す
  3. メニューを下にたどり、「ホーム画面に追加」を選ぶ
  4. 右上の「追加」を押す

ホーム画面にマークが並びます。次からはそれを押すだけで開きます。

Android

  1. Chrome で washokuzai-calendar.com を開く
  2. 右上の ︙（点が縦に三つ）を押す
  3. 「ホーム画面に追加」を選ぶ
  4. 「追加」を押す

機種により「アプリをインストール」と表示されることもあります。どちらでも同じです。

パソコン

ブックマークに入れておくと便利です。

  • Windows：Ctrl ＋ D
  • Mac：⌘ ＋ D

Chrome や Edge では、アドレス欄の右にある ⊕ から、アプリとして追加することもできます。

QRコードから開く

スマートフォンのカメラでこのQRコードを読み取ると、すぐに開きます。

Add to your home screen

Open the calendar in a single tap, like an app. It is free, and nothing needs to be installed.

iPhone and iPad

Use Safari. Other browsers, including Chrome, cannot add it.

  1. Open washokuzai-calendar.com in Safari
  2. Tap the Share button at the bottom (a square with an arrow)
  3. Scroll down the menu and choose Add to Home Screen
  4. Tap Add at the top right

An icon appears on your home screen. From then on, one tap opens it.

Android

  1. Open washokuzai-calendar.com in Chrome
  2. Tap ︙ at the top right (three dots)
  3. Choose Add to Home screen
  4. Tap Add

Some devices show Install app instead. Either works the same way.

Computer

A bookmark is the simplest way.

  • Windows: Ctrl + D
  • Mac: ⌘ + D

In Chrome and Edge you can also install it as an app from the ⊕ at the right of the address bar.

Open from a QR code

Point your phone camera at this code to open the site.

เพิ่มลงหน้าจอโฮม

เปิดปฏิทินได้ในแตะเดียวเหมือนแอป ไม่มีค่าใช้จ่ายและไม่ต้องติดตั้งอะไรทั้งสิ้น

iPhone และ iPad

ต้องใช้ Safari เบราว์เซอร์อื่นรวมถึง Chrome จะเพิ่มไม่ได้

  1. เปิด washokuzai-calendar.com ใน Safari
  2. แตะปุ่ม แชร์ ด้านล่าง (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
  3. เลื่อนเมนูลงแล้วเลือก เพิ่มลงในหน้าจอโฮม
  4. แตะ เพิ่ม ที่มุมขวาบน

ไอคอนจะปรากฏบนหน้าจอโฮม ครั้งต่อไปแตะครั้งเดียวก็เปิดได้เลย

Android

  1. เปิด washokuzai-calendar.com ใน Chrome
  2. แตะ ︙ ที่มุมขวาบน (จุดสามจุดแนวตั้ง)
  3. เลือก เพิ่มลงในหน้าจอหลัก
  4. แตะ เพิ่ม

บางเครื่องอาจขึ้นว่า ติดตั้งแอป ซึ่งใช้งานได้เหมือนกัน

คอมพิวเตอร์

บุ๊กมาร์กไว้จะสะดวกที่สุด

  • Windows: Ctrl + D
  • Mac: ⌘ + D

ใน Chrome และ Edge ยังติดตั้งเป็นแอปได้จากปุ่ม ⊕ ทางขวาของช่องที่อยู่เว็บ

เปิดจากคิวอาร์โค้ด

加入主畫面

像應用程式一樣，一按就能打開。完全免費，也不需要安裝任何東西。

iPhone、iPad

請用 Safari 開啟。Chrome 等其他瀏覽器無法加入。

  1. 用 Safari 開啟 washokuzai-calendar.com
  2. 按畫面下方的分享按鈕（方框往上的箭頭）
  3. 往下滑動選單，選擇「加入主畫面」
  4. 按右上角的「新增」

主畫面上會出現圖示，之後按一下就能打開。

Android

  1. 用 Chrome 開啟 washokuzai-calendar.com
  2. 按右上角的 ︙（直排三個點）
  3. 選擇「加到主畫面」
  4. 按「新增」

部分機型會顯示「安裝應用程式」，兩者作用相同。

電腦

加入書籤最為方便。

  • Windows：Ctrl ＋ D
  • Mac：⌘ ＋ D

在 Chrome 與 Edge 中，也可以從網址列右側的 ⊕ 安裝成應用程式。

用 QR 碼開啟

用手機相機掃描這個 QR 碼，就能立即開啟。

添加到主屏幕

像应用程序一样，一按就能打开。完全免费，也不需要安装任何东西。

iPhone、iPad

请用 Safari 打开。Chrome 等其他浏览器无法添加。

  1. 用 Safari 打开 washokuzai-calendar.com
  2. 按屏幕下方的分享按钮（方框往上的箭头）
  3. 往下滑动菜单，选择「添加到主屏幕」
  4. 按右上角的「添加」

主屏幕上会出现图标，之后按一下就能打开。

Android

  1. 用 Chrome 打开 washokuzai-calendar.com
  2. 按右上角的 ︙（竖排三个点）
  3. 选择「添加到主屏幕」
  4. 按「添加」

部分机型会显示「安装应用」，两者作用相同。

电脑

加入书签最为方便。

  • Windows：Ctrl ＋ D
  • Mac：⌘ ＋ D

在 Chrome 与 Edge 中，也可以从地址栏右侧的 ⊕ 安装为应用。

用二维码打开

用手机相机扫描这个二维码，就能立即打开。
